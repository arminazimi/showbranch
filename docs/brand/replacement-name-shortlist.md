# Replacement-name shortlist

**Checked:** 2026-10-15 (Asia/Tehran)  
**Scope:** replacement for the temporary `RepoBloom` name  
**Decision:** **Showbranch approved**; keep **GitGalleria** as the historical runner-up  
**Status:** approved by the maintainer on 2026-10-15; repository and code migration authorized

This is a product-name screen, not a legal opinion. Availability signals can change immediately and exact-string searches do not clear confusingly similar marks.

## Recommendation

### Winner: Showbranch

**Canonical identity:** `Showbranch` (wordmark), `showbranch` (CLI, npm package, Skill and plugin ID).

Showbranch is the strongest balance of meaning and ownability. “Show” communicates presentation; “branch” grounds the brand in developer work without tying the master brand to GitHub, Git, AI, or one agent vendor. It is easy to say, spell, and extend across every intended surface:

- `showbranch init`
- `npm install -g showbranch`
- `skills/showbranch/SKILL.md`
- Showbranch for Codex
- Showbranch for Claude

At the time of checking, GitHub had no exact-name repository, npm returned 404, skills.sh had no exact Skill, and registry RDAP returned no domain object for `showbranch.com`, `showbranch.io`, or `showbranch.org`. The `.com` signal is the key advantage over the other non-Git finalists. A public Claude plugin manifest contained the lowercase string `showbranch`, but only as an internal/configuration reference in an unrelated status-bar repository; it was not a plugin named Showbranch.

**Positioning fit:** “Turn your GitHub work into a portfolio worth showing.”

### Runner-up: GitGalleria

**Canonical identity:** `GitGalleria` / `gitgalleria`.

GitGalleria is vivid and category-specific: a gallery assembled from Git history. Its exact repository/package/Skill checks were clear and RDAP returned no object for the three checked domains. It loses to Showbranch because it is longer, “galleria” has less uniform pronunciation, and a Git-prefixed master brand creates avoidable dependency on another project’s trademark and category vocabulary. It remains the best fallback if explicit Git recognition is judged more valuable than long-term brand independence.

### Why the other finalists did not win

- **Patchfolio** is a compact developer/portfolio compound and all package/distribution checks were clear, but `patchfolio.com` has been registered since 2025-07-19. “Patch” can also imply fixes rather than a developer’s full body of work.
- **Devitrine** cleverly combines “dev” with *vitrine* (display case), but pronunciation is less predictable across English-speaking markets, exact web searches can split it into “de vitrine,” and `devitrine.com` has been registered since 2023-10-20.

## Trademark screen

Exact-text queries for `SHOWBRANCH`, `GITGALLERIA`, `PATCHFOLIO`, and `DEVITRINE` were screened against the official [USPTO Trademark Search](https://tmsearch.uspto.gov/search/search-results) and [EUIPO eSearch Plus](https://euipo.europa.eu/eSearch/) surfaces. No exact record was identified in this time-boxed screen. Public web-index checks restricted to official USPTO and EUIPO properties also returned no exact result.

This is **not a clearance conclusion**. The portals are JavaScript/session-driven, search results are not stable shareable artifacts, and the screen did not cover phonetic similarity, translations, logos, owners, common-law use, company registers, app stores, or a comprehensive class analysis. Before commercial launch, counsel should search similar marks in intended jurisdictions, especially Nice classes 9 and 42. GitGalleria additionally requires review against the [Git trademark policy](https://git-scm.com/about/trademark).

## Limitations

- GitHub search can lag and cannot see private repositories. A repository name is owner-scoped and search absence is not a reservation.
- npm 404 responses do not prove that a package can be claimed or that a matching organization scope is available.
- skills.sh search is fuzzy and may lag publication; the analysis counted exact `name` or `skillId` matches, not unrelated fuzzy results.
- Public code search cannot see private, unpublished, pending-review, account-specific, or workspace plugins. Codex/ChatGPT and Claude do not expose a complete authoritative public-name availability API.
- RDAP 404 means that the registry returned no domain object at that moment. It is not a registrar checkout, premium-price check, or reservation. `.dev` could not be determined because the Google Registry endpoint returned HTTP 403 to this client.
- Social handles were not checked because “not found” responses are not authoritative and the task did not authorize claiming them.
- No candidate was tested with target users. Pronunciation and recall scores are informed judgments that should be validated before visual identity work.
